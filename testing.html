Bcrypt

Here we can confirm that bcrypt is properly hashing passwords and the hashed passwords are being stored in database instead of the raw credential.


JWT Postman

Using Postman, we can hit the login endpoint with valid credentials and confirm that a JWT token is returned. Don't worry, these expire after one hour.


Using the token received in the previous step, we can verify that authenticated requests are granted access to protected routes as expected.


Confirming the inverse, we can see that protected routes reject unauthorized requests when no valid JWT is present.

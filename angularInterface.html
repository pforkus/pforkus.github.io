Angular App

This is the landing page of the Angular application, which provides search, category filtering, sorting, and the ability to add, edit, and delete items. By default, all data and functionality are hidden until the user authenticates.


This screenshot shows the login form, which accepts a username and password. Basic validation is enforced, preventing submission if either field is empty.


Upon successful login, the data table is populated, full functionality is enabled, and the login button is replaced with a logout button.


Selecting an item enables the edit and delete buttons for that entry. Selecting multiple items allows users to batch delete inventory records.


Clicking edit with an item selected opens a form pre-populated with that item's current values. The user can modify any fields and either save the changes to the database or discard them and return to the dashboard.


Searching in the Angular app mirrors the Android app, it queries the database with the provided name and returns only matching results for display.


The add item form mirrors the edit form but starts empty, allowing users to fill in the details for a new item and save it to the database, or discard and return to the dashboard.


Category filtering in the Angular interface is handled via a dropdown populated with the current inventory categories. Selecting one filters the results to only items belonging to that category.


The final screenshot shows the sort functionality sorting the results by price in descending order.

Login

Final

While much did not change on the Login screen, there was one addition. As the app's backend is deployed to Render, on app load, the Android app pings the server to wake it up, and a spinner and message are displayed as the app waits for a repsonse. Likewise, while waiting, the create and login buttons are disabled to prevent failed login or registration attempts.

Dashboard

Original

Final

The dashboard activity highlights several key differences between the original and enhanced application. Originally, the toolbar served only as a static label, item cells displayed only their names and quantities and were confined to a fixed three-column grid layout, and each cell contained its own delete button.

The enhanced version expands the toolbar with a search icon, hamburger menu, and overflow menu. A category ChipGroup now dynamically populates with the current inventory categories, enabling quick filtering. The per-cell delete button has been removed in favor of an Action Mode where long-pressing an item activates a Contextual Action Bar, providing support for both single and batch deletions. Finally, the default layout has been changed to a two column layout from three, adding more space to accomodate the addition of the price field.

Item Dialog Fragment

Original

Final

When migrating from Room to MongoDB, I took the opportunity to expand the data model with additional fields, SKU, price, date created/modified, and category, to make inventory records more descriptive. These schema changes required updating the Android app accordingly, with the item dialog fragments revised to display, accept, and submit the new fields.

Android New Features

Overflow Menu

Sort BottomSheet

List View

These screenshots illustrate the overflow menu and its functionality. The first image shows the dropdown that appears when the overflow icon is tapped, revealing the available options. Selecting "Sort" opens a bottom sheet allowing users to sort inventory by name, category, date added, or price, in either ascending or descending order. Selecting "Toggle Layout" switches the default two-column card grid to a single-column list view, where each item displays its name, category, quantity, and price. This alternate layout helps users with larger inventories quickly scan and compare items without having to open each one individually.
